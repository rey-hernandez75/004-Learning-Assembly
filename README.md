# 004-Learning-Assembly

## 🇺🇸 English

### Purpose

This repository documents my journey of learning Assembly Language through structured study, practical exercises, and well-documented source code.

The primary goal is to build a solid foundation in low-level programming, computer architecture, processor organization, memory management, and software development using Assembly Language.

All source code in this repository is part of my personal learning plan and is organized by topics to provide a clear and progressive learning path.

### Repository Structure

- Programs organized by topics.
- Well-documented source code.
- Practical exercises.
- Notes and examples.
- Progressive learning approach.
